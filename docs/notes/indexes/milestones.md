## Recording milestone changes from now on

Use `zk milestone --title "Milestone N: the result or change"`. Link its
investigations, decisions, candidate identity, and validation limits. Record
completion only when the full exit is established; retargeting and deferral
do not imply completion. Keep remaining actions and current state in `todo.md`.

Add new milestone records to this map. Use `zk list docs/notes --tag milestone`
to search both imported and maintained records.
